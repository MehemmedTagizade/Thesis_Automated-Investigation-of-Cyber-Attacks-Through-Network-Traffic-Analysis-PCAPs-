Automated Investigation of Cyber Attacks Through Network Traffic Analysis (PCAPs)
This project applies machine learning models to automate the investigation of cyber attacks using network traffic data (PCAPs). It focuses on classification (e.g., DDoS detection) and anomaly detection.

Main Folders
ANOMALY DETECTION/ – Unsupervised models (Isolation Forest, LOF)

CLASSIFICATION/ – Supervised models (Random Forest, SVM, Decision Tree)

PRACTICE/ – Initial tests and experiments

Dataset
Source: ISCX 2016 dataset (Friday-WorkingHours-Afternoon-DDos.pcap_ISCX.csv)

Features: Flow duration, packets, bytes, etc.

Preprocessing: Missing value handling, feature selection, standardization.


Models Used
Random Forest, SVM, Decision Tree (Classification)

Isolation Forest, Local Outlier Factor (Anomaly Detection)

Goal
Detect network attacks and anomalies automatically using machine learning.
